Developer Integrations

Bring Skolem directly into your terminal, CI/CD pipeline, or IDE.

Command Line Interface (CLI)

Verify migrations and AI-generated queries from your terminal or automate them in GitHub Actions and GitLab CI.

git clone https://github.com/NguyenTienDat377/Skolem && cd Skolem
pipx install ./cli

export SKOLEM_API_KEY=skm_your_key_here
skolem verify --ddl schema.sql --v1 original.sql --v2 generated.sql
Get your API Key

Model Context Protocol (MCP) Server

Let Claude Desktop, Cursor, or your favorite AI IDE verify queries automatically during code generation.

Claude Desktop Configuration (claude_desktop_config.json):

{ "mcpServers": { "skolem": { "command": "/abs/path/to/Skolem/mcp/.venv/bin/python", "args": ["/abs/path/to/Skolem/mcp/skolem_mcp.py"], "env": { "SKOLEM_API_KEY": "skm_your_key_here", "SKOLEM_URL": "https://skolem.dev" } } } }
