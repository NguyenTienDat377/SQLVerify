1. What SQLVerify is

SQLVerify is a formal verification tool that uses SMT (Z3) solving to check whether two SQL queries are semantically equivalent given a database schema, and to generate a counterexample database when they are not. It is a decision-support tool intended to help engineers review SQL before it ships — it is not a substitute for your own testing, code review, or judgment.
